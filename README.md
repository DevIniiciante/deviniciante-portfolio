# DevIniciante — Portfólio

Site institucional estático da DevIniciante. O portfólio apresenta Victor Oliveira Lima, projetos selecionados, serviços e contato comercial.

## Desenvolvimento

Execute `python3 -m http.server 8000` na raiz e abra `http://localhost:8000`. O site usa HTML, CSS e JavaScript com GSAP e ScrollTrigger locais. Os arquivos das fontes Manrope e Space Grotesk vêm acompanhados das respectivas licenças.

## Publicação

O GitHub Pages usa a raiz da branch `main`. Todos os caminhos internos de arquivos são relativos para funcionar no subdiretório `/deviniciante-portfolio/`. A URL canônica, a imagem de compartilhamento e o sitemap estão configurados para esse endereço.
